# 토토 분석기 (개인용)

베트맨의 **프로토 승부식**과 **축구토토 승무패** 회차 경기를 수집하고, API-Football 데이터(최근 폼, 상대전적, 부상·결장, 라인업)로 확률을 추정합니다. 그 결과로 **하루 한도(기본 3만원)** 안에서 조합과 마킹을 추천하는 도구입니다.

> 확률 추정일 뿐 적중을 보장하지 않습니다. 환급률이 100% 미만이라 장기적으로는 손실이 나기 쉽습니다. 한도 기능과 손익 기록을 꼭 같이 쓰세요.

## 구성
- `collector/`: 내 PC에서 실행하는 수집기(Python)
  - `collect.py`: 실행 파일. 베트맨 수집 → 분석 데이터 → `web/data/latest.json`
  - `betman_api.py`: 베트맨 내부 JSON으로 회차·배당 받기 (기본 방식, 브라우저 불필요)
  - `betman_fetch.py`, `betman_parser.py`: JSON 방식이 막혔을 때 쓰는 브라우저 화면 수집과 텍스트 파서
  - `football.py`: API-Football 클라이언트. 예측, 부상, 라인업을 받고 디스크 캐시로 하루 호출 한도를 관리합니다.
  - `footballdata.py`: football-data.co.uk 무료 CSV(키 불필요). 5대 리그와 챔피언십, 네덜란드·포르투갈·스코틀랜드 리그의 최근 폼, 홈/원정 득실(xG 반영), 상대전적을 계산합니다.
  - `matching.py`, `team_alias.json`: 한글 팀명과 영문 팀명을 연결합니다. 한쪽 팀만 맞은 경기는 `team_alias_learned.json`에 자동으로 학습합니다.
- `tests/run_offline.py`: 베트맨 접속 없이 가짜 회차로 전체 흐름을 시험합니다.
- `web/index.html`: 분석 웹(경기 분석 / 프로토 조합 / 승무패 마킹 / 손익 기록 / 설정)

## 처음 설정
1. Python 3.10 이상을 설치합니다. Windows에서는 설치할 때 "Add to PATH"를 체크하세요.
2. API-Football 무료 키를 발급합니다. https://dashboard.api-football.com/register 에서 가입한 뒤 Account → My Access 에서 키를 복사합니다.
3. `collector/.env.example`을 `collector/.env`로 복사하고 `API_FOOTBALL_KEY=` 뒤에 키를 붙여넣습니다. 키는 채팅 등 다른 곳에 올리지 마세요.
4. 실행합니다.
   - Windows: `run_windows.bat` 더블클릭
   - Mac: 터미널에서 `./run_mac.sh`

   첫 실행 때 필요한 패키지와 브라우저를 자동으로 설치하고, 수집이 끝나면 분석 웹이 열립니다.
5. 처음에는 점검을 먼저 해 보세요: `collector` 폴더에서 `python collect.py --check`
   API 키 상태(요금제, 오늘 사용량)와 베트맨 접속 여부를 알려줍니다.

## 실행 옵션 (`collector` 폴더에서 `python collect.py ...`)
| 옵션 | 설명 |
|---|---|
| `--serve` | 수집 후 분석 웹 열기 |
| `--check` | API 키와 베트맨 접속만 점검 |
| `--proto-ts 260125` / `--toto-ts ...` | 회차를 직접 지정 (자동 탐색이 안 될 때) |
| `--browser` | JSON 방식 대신 브라우저 화면으로 수집 |
| `--no-stats` | football-data 무료 통계 생략 |
| `--manual` | 브라우저를 띄우고, 직접 베트맨 구매 화면을 연 뒤 Enter를 눌러 수집 (자동 수집이 안 될 때) |
| `--show` | 자동 수집 과정을 화면에 보이기 |
| `--from-text a.txt --toto-text b.txt` | 베트맨 경기표를 복사해 둔 텍스트 파일로 수집 |
| `--no-api` | API-Football 호출 안 함 |
| `--serve-only` | 수집 없이 웹만 열기 |

## 하루 사용 흐름
1. 오전에 한 번 실행해서 회차 경기와 상대전적·부상 정보를 받습니다.
2. 킥오프 1시간 전쯤 다시 실행하면 발표된 라인업이 반영됩니다. 라인업은 킥오프 90분 이내 경기만 조회합니다.
3. 웹의 **프로토 조합** / **축구승무패** 탭에서 추천을 확인합니다.
4. 실제로 산 것은 "구매 기록"을 누르고, 결과가 나오면 **기록·손익** 탭에서 적중/미적중을 표시합니다.

## 데이터 출처와 수집 순서
1. **베트맨**: 내부 JSON(`inqCacheBuyAbleGameInfoList.do`, `gameInfoInq.do`)으로 회차, 경기, 배당을 받습니다. 실패하면 브라우저 화면 수집으로 넘어가고, 그것도 안 되면 복사한 텍스트를 쓰면 됩니다.
2. **API-Football**(키 필요): 예측 확률, 최근 폼, 상대전적, 부상·결장, 라인업을 받습니다.
3. **football-data.co.uk**(키 불필요): API에서 데이터를 못 받은 경기의 폼, 득실, 상대전적을 채웁니다. 무료 요금제가 이번 시즌을 지원하지 않거나 한도가 찼을 때도 이것으로 분석합니다.

## 분석 방식
- **확률 모델**
  - 푸아송 득점 모델: 홈팀 홈 득점·원정팀 원정 실점 평균에 최근 5경기 폼 차이와 결장자 수를 보정합니다.
  - API-Football 예측 확률을 함께 씁니다.
  - 상대전적은 최근 6경기를 씁니다.
- **최종 확률** = 배당에서 계산한 확률 × 시장 반영 비율 + 모델 확률 × (1 − 비율). 비율은 설정에서 바꿀 수 있고 기본값은 0.6입니다.
- **EV(기대값)** = 최종 확률 × 배당 − 1. 플러스면 배당이 후한 선택입니다.
- **프로토 조합**
  - 같은 경기의 여러 유형은 한 조합에 넣지 않습니다.
  - 2~3폴더 조합 중 EV가 높은 것을 고릅니다.
  - 금액은 켈리 비율로 나누고 1,000원 단위로 맞춥니다.
- **승무패**
  - 각 경기에서 가장 확률이 높은 결과 하나로 시작합니다.
  - 정해진 예산 안에서, 적중확률을 가장 많이 올리는 복수 선택을 하나씩 추가합니다.
  - 투표율이 있으면, 모델 확률이 투표율보다 높은 선택에 ★를 표시합니다.

## 문제가 생기면
- **경기를 하나도 인식하지 못했다고 나올 때**: `collector/raw/` 폴더의 최신 `betman_*.json` 파일을 보내주시면 실제 응답에 맞춰 고쳐 드립니다. 그동안은 `--manual`로 실행하거나, 웹의 "직접 붙여넣기"를 쓰세요.
- **승무패 회차를 못 찾을 때**: 베트맨에서 회차 번호를 확인하고 `--toto-ts`로 지정하세요.
- **팀 매칭 실패**: 웹 데이터 탭에 나오는 팀을 `team_alias.json`에 `"베트맨표기": ["영문 팀명 일부"]` 형식으로 추가하세요.
- **API 한도**: 무료는 하루 100회입니다. 같은 경기는 캐시되므로 다시 실행해도 호출이 늘지 않습니다(라인업 제외). `MAX_FIXTURES`로 분석할 경기 수를 줄일 수 있습니다.
